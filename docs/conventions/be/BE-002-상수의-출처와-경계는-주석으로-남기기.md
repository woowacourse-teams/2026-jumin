# 상수의 출처와 경계는 주석으로 남기기

출처와 포함·제외 경계를 설명하는 짧은 주석을 상수 옆에 둔다.

- 범위: CSV 날짜 검증의 DB 허용 범위처럼 외부 기준을 나타내는 상수
- 상태: 후보 · 논의 이견 · 구현 반영 · 재검토 필요

**설명용 예시**

변경 전

```java
private static final int MIN_SIZE = 1;
private static final int MAX_SIZE_EXCLUSIVE = 100;
```

변경 후

```java
// 외부 규격의 최소값 이상, 최대값 미만 범위다.
private static final int MIN_SIZE = 1;
private static final int MAX_SIZE_EXCLUSIVE = 100;
```

근거: 작성자는 날짜 값만으로 범위를 정한 근거를 알기 어려워 PostgreSQL 기준이라는 설명을 유지한다고 답했다.

- 반례·반론: 리뷰어는 중요한 주석이 아니라고 지적했고 작성자는 출처와 경계 설명을 이유로 유지했다. 이후 명시적 동의는 확인하지 못했다.
- 한계: 모든 상수나 코드 동작을 반복 설명하는 주석을 요구하는 규칙은 아니다.
