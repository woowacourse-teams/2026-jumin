# 긴 빌더 설정은 생성 메서드로 분리하기

빌더 구성을 의미 있는 생성 메서드로 추출하고 호출부에는 생성 호출을 둔다.

- 범위: CSV 파서의 BOMInputStream 생성과 유사한 국소 설정 코드
- 상태: 후보 · 논의 제안 · 구현 반영

**설명용 예시**

변경 전

```java
try (Input input = Input.builder()
        .source(bytes)
        .detectBom(true)
        .build()) {
    decode(input);
}
```

변경 후

```java
try (Input input = createInput(bytes)) {
    decode(input);
}

private Input createInput(byte[] bytes) {
    return Input.builder()
            .source(bytes)
            .detectBom(true)
            .build();
}
```

근거: 처리 흐름과 생성 옵션을 나눠 호출부를 짧게 읽을 수 있다. (추론)

- 한계: 모든 builder를 분리하거나 별도 팩토리 클래스를 만들라는 근거는 아니다.
