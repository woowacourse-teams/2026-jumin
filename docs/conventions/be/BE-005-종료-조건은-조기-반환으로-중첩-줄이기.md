# 종료 조건은 조기 반환으로 중첩 줄이기

종료 조건에서 먼저 반환하고 정상 작업을 바깥 흐름에 둔다.

- 범위: CSV 동기화와 유사한 독립 메서드의 종료 분기
- 상태: 후보 · 논의 제안 · 구현 미반영

**설명용 예시**

변경 전

```java
void saveRows(List<Row> rows) {
    if (!rows.isEmpty()) {
        save(rows);
    }
}
```

변경 후

```java
void saveRows(List<Row> rows) {
    if (rows.isEmpty()) {
        return;
    }
    save(rows);
}
```

근거: 리뷰는 CSV 동기화 코드의 깊이를 줄이기 위해 early return 사용을 제안했다.

- 반례·반론: 리뷰 대상의 신규 행 처리 중첩은 병합 트리와 현재 코드에 남아 있고, 반영 답글이나 연결되는 수정은 확인하지 못했다.
- 한계: 루프에서 return하면 다음 배치까지 종료될 수 있다. 원래 후속 작업을 건너뛰는 단순 치환은 하지 않는다.
