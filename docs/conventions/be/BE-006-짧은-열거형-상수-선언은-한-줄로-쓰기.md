# 짧은 열거형 상수 선언은 한 줄로 쓰기

단순한 enum 상수의 이름과 인자를 한 줄에 작성한다.

- 범위: 서버 ErrorCode와 유사한 짧은 enum 상수 선언
- 상태: 후보 · 논의 제안 · 구현 반영

**설명용 예시**

변경 전

```java
FAILED(
        HttpStatus.INTERNAL_SERVER_ERROR,
        "처리하지 못했습니다.");
```

변경 후

```java
FAILED(HttpStatus.INTERNAL_SERVER_ERROR, "처리하지 못했습니다.");
```

근거: 같은 에러 코드 목록에서 선언 모양을 맞추어 항목을 비교하기 쉽게 한다. (추론)

- 한계: 글자 수 제한이나 긴 인자 목록 처리까지 정한 리뷰는 아니다. 실제 수정에는 메시지 축약도 있었지만 아래 예시는 문구를 보존한 서식만 보여준다.
