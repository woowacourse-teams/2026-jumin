# 같은 게스트 식별자는 같은 용어로 부르기

동일한 식별자를 나타내는 매개변수와 내부 참조도 guestId로 맞춘다.

- 범위: 좋아요 API의 게스트 식별자와 직접 대응하는 변수
- 상태: 후보 · 논의 동의 · 구현 반영

**설명용 예시**

변경 전

```java
void like(@RequestHeader("X-Guest-Id") String anonymousId) {
    service.like(UUID.fromString(anonymousId));
}
```

변경 후

```java
void like(@RequestHeader("X-Guest-Id") String guestId) {
    service.like(UUID.fromString(guestId));
}
```

근거: 리뷰는 헤더와 컨트롤러 변수의 용어를 맞추면 일관될 것이라고 설명했고 작성자가 수용했다.

- 한계: 외부 헤더나 DB 컬럼의 계약까지 스타일만으로 바꾸는 규칙이 아니다.
