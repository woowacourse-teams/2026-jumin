# 서비스 로그 문장은 한국어로 맞추기

사람이 읽는 로그 메시지 문장은 한국어로 맞춘다.

- 범위: 주차장 검색·상세 서비스가 작성하는 로그 설명 문장
- 상태: 후보 · 논의 제안 · 구현 반영

**설명용 예시**

변경 전

```java
log.atInfo().setMessage("Parking search completed")
        .addKeyValue("resultCount", count).log();
```

변경 후

```java
log.atInfo().setMessage("주차장 검색이 완료되었습니다.")
        .addKeyValue("resultCount", count).log();
```

근거: 같은 서비스의 로그 설명에 한국어와 영어가 섞이지 않도록 표기를 통일한다. (추론)

- 한계: 구조화 로그의 필드명·상태값, 외부 라이브러리 로그까지 번역하는 규칙은 아니다.
