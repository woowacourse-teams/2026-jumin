# 짧은 문자열 호출은 한 줄로 쓰기

호출이 짧으면 메서드 이름 앞에서 불필요하게 줄을 나누지 않는다.

- 범위: 관리자 인증의 짧은 문자열 메서드 호출과 유사한 표현
- 상태: 후보 · 논의 제안 · 구현 반영
- 예외: stream과 builder처럼 단계가 이어지는 호출은 같은 한 줄 규칙으로 묶지 않는다.

**설명용 예시**

변경 전

```java
boolean matches = expected
        .equals(actual);
```

변경 후

```java
boolean matches = expected.equals(actual);
```

근거: 리뷰어는 equals 같은 메서드는 한 줄에 있어야 이해하기 쉽다고 설명했다.

- 한계: 작성자의 일반 규칙 채택 답변은 확인하지 못했다. Optional 후처리 줄바꿈과는 적용 범위가 다르다.
