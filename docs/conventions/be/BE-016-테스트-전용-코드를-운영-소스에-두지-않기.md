# 테스트 전용 코드를 운영 소스에 두지 않기

테스트만을 위해 운영 코드에 메서드·생성자·접근자·분기·설정이나 테스트 훅을 추가하지 않는다. 테스트 전용 fixture와 helper는 테스트 소스에 둔다.

- 범위: `server/src/main`의 운영 코드와 `server/src/test`의 테스트 코드
- 상태: 사용자 명시 채택
- 예외: Spring 설정 바인딩·JPA·직렬화·라이프사이클처럼 실제 실행에 필요한 코드와 운영 책임에 맞는 의존성 주입은 유지한다.

테스트는 실제 운영 진입점과 공개 동작을 검증한다. private 메서드를 테스트하려고 접근 범위를 넓히거나 운영 코드에 테스트 전용 실행 경로를 만들지 않는다. 테스트 가능성을 위한 정상적인 역할 분리와 의존성 주입을 금지하는 규칙은 아니다.

근거: 사용자가 미사용·테스트 전용 메서드 제거와 이 규칙의 컨벤션 문서 추가를 명시적으로 요청했다.
