# 로그 호출은 별도 메서드로 분리하기

로그에 사용할 값의 준비·조건 판단과 실제 로그 호출을 분리한다. `log.atInfo()...log()`처럼 로그를 작성하는 코드는 같은 클래스의 별도 private 메서드에 둔다.

- 범위: 서버 Java의 로그 작성 코드
- 상태: 사용자 명시 채택

호출부에서 필요한 값을 정리해 전달하고, 로그 전용 메서드는 전달받은 값으로 로그를 작성한다. 이미 로그용 메서드가 있어도 값의 준비·조건 판단과 실제 로그 호출이 섞여 있다면 분리한다.

**설명용 예시**

변경 전

```java
private void logRequestCompleted(boolean isHealthCheck) {
    String requestType = "application";
    if (isHealthCheck) {
        requestType = "health";
    }
    log.atInfo()
            .setMessage("HTTP request completed")
            .addKeyValue("requestType", requestType)
            .log();
}
```

변경 후

```java
private void logRequestCompleted(boolean isHealthCheck) {
    String requestType = "application";
    if (isHealthCheck) {
        requestType = "health";
    }
    writeRequestLog(requestType);
}

private void writeRequestLog(String requestType) {
    log.atInfo()
            .setMessage("HTTP request completed")
            .addKeyValue("requestType", requestType)
            .log();
}
```

근거: 사용자 명시 채택
