# 분석 이벤트 이름은 상수로 참조하기

이벤트 문자열을 직접 반복하지 않고 의미 있는 이름의 기존 이벤트 상수를 사용한다.

- 범위: 프런트엔드 GA4 이벤트 이름과 그 호출부
- 상태: 후보 · 논의 동의 · 구현 반영

**설명용 예시**

변경 전

```typescript
trackEvent('home_parking_marker_clicked');
```

변경 후

```typescript
import { eventName } from './constants';

trackEvent(eventName.HOME_PAGE_MARKER);
```

근거: 리뷰는 제한된 수집 태그를 상수 이름으로 참조하면 알아보기 쉽다고 설명했고 작성자가 동의했다.

- 한계: 이벤트 전송값은 그대로 보존한다. 모든 이벤트 호출을 새 커스텀 훅으로 옮기는 규칙은 아니며 그 별도 제안에는 반대 답글이 있었다.
