# 콜백은 화살표 표현을 우선하기

prefer-arrow-callback 선언에 맞춰 콜백 위치에서 화살표 표현을 우선한다.

- 범위: client ESLint의 **/*.{ts,tsx} 명시 rules 선언 범위
- 상태: 후보 · 논의 미확인 · 구현 반영

**설명용 예시**

변경 전

```typescript
const doubled = values.map(function (value: number) {
  return value * 2;
});
```

변경 후

```typescript
const doubled = values.map((value: number) => {
  return value * 2;
});
```

근거: 개별 규칙 선택 이유는 원문에서 확인하지 못했다.

- 한계: 고정 9d3a7817와 별도 320cf372의 명시 rules 선언이 같다. recommended 확장과 마지막 eslintConfigPrettier를 합친 실효 설정은 실행·계산하지 않아 최종 강제 수준으로 단정하지 않는다.; 설정 주석은 Airbnb를 참고해 선별했다고 말한다. 개별 선택 이유와 논의 합의는 미확인이며 Airbnb 전체 지침을 가져오지 않는다.; 동적 this·arguments 동작을 보존해야 하는 코드는 단순 변환하지 않는다. 이 의미 보존 조건은 검토 한계이며 저장소가 합의한 새 예외를 뜻하지 않는다.; 모든 함수·컴포넌트 강제와 다르다. react/function-component-definition 제거 및 arrow-body-style의 always→as-needed→제거 이력을 지우지 않는다.
