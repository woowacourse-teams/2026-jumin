# 함수 매개변수 재대입을 피하기

no-param-reassign 선언에 맞춰 매개변수 자체를 다시 대입하지 않는다.

- 범위: client ESLint의 **/*.{ts,tsx} 명시 rules 선언 범위
- 상태: 후보 · 논의 미확인 · 구현 반영

**설명용 예시**

변경 전

```typescript
const increment = (value: number) => {
  value = value + 1;
  return value;
};
```

변경 후

```typescript
const increment = (value: number) => {
  const nextValue = value + 1;
  return nextValue;
};
```

근거: 개별 규칙 선택 이유는 원문에서 확인하지 못했다.

- 한계: 고정 9d3a7817와 별도 320cf372의 명시 rules 선언이 같다. recommended 확장과 마지막 eslintConfigPrettier를 합친 실효 설정은 실행·계산하지 않아 최종 강제 수준으로 단정하지 않는다.; 설정 주석은 Airbnb를 참고해 선별했다고 말한다. 개별 선택 이유와 논의 합의는 미확인이며 Airbnb 전체 지침을 가져오지 않는다.; 매개변수 객체의 속성 변경까지 금지한다는 별도 옵션은 선언되지 않았다. 불변성 설계 전반으로 확대하지 않는다.
