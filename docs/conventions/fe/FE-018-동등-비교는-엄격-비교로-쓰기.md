# 동등 비교는 엄격 비교로 쓰기

eqeqeq: ['error', 'always'] 선언에 맞춰 ===와 !==를 사용한다.

- 범위: client ESLint의 **/*.{ts,tsx} 명시 rules 선언 범위
- 상태: 후보 · 논의 미확인 · 구현 반영

**설명용 예시**

변경 전

```typescript
const isEmpty = (count: number) => count == 0;
```

변경 후

```typescript
const isEmpty = (count: number) => count === 0;
```

근거: 개별 규칙 선택 이유는 원문에서 확인하지 못했다.

- 한계: 고정 9d3a7817와 별도 320cf372의 명시 rules 선언이 같다. recommended 확장과 마지막 eslintConfigPrettier를 합친 실효 설정은 실행·계산하지 않아 최종 강제 수준으로 단정하지 않는다.; 설정 주석은 Airbnb를 참고해 선별했다고 말한다. 개별 선택 이유와 논의 합의는 미확인이며 Airbnb 전체 지침을 가져오지 않는다.; 강제 형변환에 의존하는 기존 비교를 연산자만 바꾸면 동작이 달라질 수 있다. 예시는 number 값끼리 비교한다.
