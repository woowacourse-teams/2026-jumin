# 공통 줄높이는 단위 없는 배율로 두기

고정 px 길이 대신 1.3·1.4·1.5처럼 단위 없는 배율을 토큰으로 정의한다.

- 범위: client/src/theme/font.ts의 lineHeight 토큰
- 상태: 후보 · 논의 미확인 · 구현 반영

**설명용 예시**

변경 전

```typescript
const textStyle = css`
  font-size: 16px;
  line-height: 22.4px;
`;
```

변경 후

```typescript
const lineHeight = { 140: 1.4 } as const;
const textStyle = css`
  font-size: 16px;
  line-height: ${lineHeight[140]};
`;
```

근거: 파일 주석은 각 요소의 글자 크기에 비례하도록 구성한다고 명시한다.

- 한계: 예시는 자식이 없는 16px 텍스트의 22.4px 줄높이를 보존하는 설명용 조각이다. px와 배율의 상속 의미까지 항상 동등하다는 치환 규칙은 아니다.; 글자 크기가 달라져도 같은 배율을 적용할 공통 토큰 범위다. 모든 CSS의 고정 줄높이를 일괄 교체하거나 접근성 효과·팀 합의를 추정하지 않는다.
