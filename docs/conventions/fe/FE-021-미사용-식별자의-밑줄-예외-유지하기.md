# 미사용 식별자의 밑줄 예외 유지하기

TypeScript no-unused-vars의 warn 선언을 유지하며 ^_로 시작하는 인수·변수 이름은 검사 예외로 둔다.

- 범위: client ESLint의 **/*.{ts,tsx} 명시 rules 선언 범위
- 상태: 후보 · 논의 미확인 · 구현 반영
- 예외: argsIgnorePattern과 varsIgnorePattern에 따라 ^_로 시작하는 인수·변수 이름을 검사에서 제외한다.

**설명용 예시**

변경 전

```typescript
const handleCancel = (event: MouseEvent) => closeSheet();
```

변경 후

```typescript
const handleCancel = (_event: MouseEvent) => closeSheet();
```

근거: 개별 규칙 선택 이유는 원문에서 확인하지 못했다.

- 한계: 고정 9d3a7817와 별도 320cf372의 명시 rules 선언이 같다. recommended 확장과 마지막 eslintConfigPrettier를 합친 실효 설정은 실행·계산하지 않아 최종 강제 수준으로 단정하지 않는다.; 설정 주석은 Airbnb를 참고해 선별했다고 말한다. 개별 선택 이유와 논의 합의는 미확인이며 Airbnb 전체 지침을 가져오지 않는다.; 경고를 오류·금지로 바꾸어 설명하지 않는다. 기본 no-unused-vars는 off이고 TypeScript 전용 규칙을 쓴다.; 2026-08-06 ef91d46에서 TypeScript 규칙의 error→warn 완화를 확인했다. 실제 도구 실행 결과나 개별 완화 이유는 확인하지 않았다.
