# 개발 서버 설정

`develop`은 개발 서버의 배포 기준 브랜치이고, `main`은 운영 서버의 배포 기준 브랜치입니다.

애플리케이션과 인프라 제공자가 아직 정해지지 않아, 이 레포지토리에는 배포 워크플로를 포함하지 않았습니다. 개발 서버를 열기 전에 다음 항목을 결정해 `infra/`에 기록합니다.

- 호스팅 및 런타임 제공자
- 클라이언트와 서버의 빌드 명령
- `.env.example` 파일에 정의할 환경 변수 이름
- `develop` 브랜치에서 실행되는 배포 워크플로
- 헬스 체크 URL과 롤백 절차

실제 비밀 정보는 레포지토리가 아닌 배포 플랫폼의 시크릿 저장소에서 관리합니다.
