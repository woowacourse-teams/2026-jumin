# OSM 전국 보행망 적재는 GitHub Actions 밖에서 수동 실행

- 상태: Accepted
- 결정일: 2026-10-12
- 범위: OSM 보행망의 변환·적재, GitHub Actions, 데이터 갱신 운영
- 대체 결정: 없음
- 관련 자료: [OSM 적재 안내](../../README.md#osm-보행-네트워크-적재), [적재 스크립트](../../../infra/scripts/import-osm-walking-network.sh), [Server CI](../../../.github/workflows/server-ci.yml)

## 문제와 제약

한국 전국 OSM 원본을 보행 네트워크로 변환하고 DB에 적재하는 작업은 큰 계산·디스크 자원을 요구한다. 현재 GitHub Actions의 실행 사양으로는 이 작업을 안정적으로 처리할 수 없다.

## 결정

OSM 다운로드·변환·적재를 실행하는 GitHub Actions 워크플로를 제거한다. 전국 데이터 처리는 자원이 충분한 로컬 또는 별도 호스트에서 운영자가 수동으로 실행한다. 수동 실행에서는 원본 PBF 날짜나 파일, 또는 미리 변환한 그래프 디렉터리를 지정할 수 있다.

## 근거와 결과

- 현재 Actions 자원으로 감당하기 어려운 전국 데이터 처리를 CI에서 실행하지 않는다.
- GitHub Actions에서는 OSM 데이터가 자동으로 갱신되지 않는다. 데이터 갱신 시 자원이 충분한 호스트에서 적재 스크립트를 실행해야 한다.
- 변환·적재 스크립트와 Server CI의 일반 백엔드 검증은 유지한다.

## 재검토 조건

전국 변환에 필요한 CPU, 메모리, 임시 디스크와 실행 시간을 제공하는 runner가 마련되면 전체 변환·적재를 검증한 뒤 자동화를 다시 검토한다.
